## 与 iOS 的对齐内容

复用 iOS 的三张引导插画与产品拍摄素材原文件；移植背景渐变及光晕位置、紫色强调色、黑色主按钮、白色/深色卡片、三页轮播、分页点、图片边缘遮罩与预估进度曲线。预估进度不会触发请求成功，结果始终以服务端响应为准。

首页、护肤柜、肌肤检测三项底栏，个人中心位于标题栏；成分报告采用「功效 / 风险 / 建议 / 成分」目录。移除活动页面中虚构成就、假计数、图片占位外链、未知开封日期和未经记录的肌肤判断。保留真实字段、空状态、失败重试和用户确认流程。

HarmonyOS 登录采用现有手机账号，选图和拍照采用系统能力。深色适配和辅助文字对比度按 HarmonyOS 要求补充。这是已实现的视觉和交互对齐，**未做 iOS 与 HarmonyOS 所有页面、机型的逐像素比对，不能声称全量 1:1 验收完成**。

## 网络及数据修复

- 普通请求独立创建/释放 HTTP 对象，避免并发共享句柄；AI 请求读超时调整为 120 秒。
- SDK 20 的 NetworkKit RequestMethod 不含 PATCH；拍摄状态改用 RemoteCommunicationKit 的真实 PATCH 请求，原生保存获得服务端 200 并回显。
- 对接服务端真实方案生成、采用、每日读取/打卡；只在服务端确认后更新勾选状态。保留时区冲突错误，不假装保存成功。
- 开封状态区分未记录、未开封、已开封，不用创建日期伪造开封日。
- 当前服务端把检测照片存于阿里云私有 OSS，通过短期签名链接用于 AI 处理及历史回看，删除记录/注销账号时删除。已修正旧版「腾讯 COS、分析后立即删除、仅留结构化结果」的不实说明。
- 保留已有仓库清理：移出跟踪的依赖目录、旧构建包、本机路径和签名材料，新增忽略规则。移除文件不等于撤销旧证书，本次未修改 AGC 签名配置。
- 应用仅声明 INTERNET。系统选图/拍照不申请全量相册读取权限；上传前说明处理方及用途并征得本次同意。

## 构建与本地调试

安装 DevEco Studio 及其配套 SDK/JBR 后执行：

```sh
./scripts/build-local.sh production
```

默认构建副本为 `$HOME/DevEcoStudioProjects/AIskin-HarmonyOS-Build`，可通过 `AISKIN_BUILD_DIR` 设置其他独立 ASCII 路径。production 使用正式 HTTPS API 和 release 构建；`local` 使用 127.0.0.1:5001 与 debug 构建，仅改变副本。HAP 路径为副本内 `entry/build/default/outputs/default/entry-default-unsigned.hap`。先检查端口及旧进程，再启动服务端；模拟器访问本地服务须配置 `hdc rport tcp:5001 tcp:5001`。
