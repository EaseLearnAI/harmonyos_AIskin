# 📄 **二、《隐私政策（Privacy Policy）》**


我们十分重视您的隐私与个人信息保护。本隐私政策将说明我们如何收集、使用、存储和保护您的信息。使用本应用即表示您同意本政策。

---

# **1. 我们收集的信息**

我们可能会收集以下类别的信息：

### **1.1 您主动提供的信息**

* 面部照片（用于肤质识别算法）
* 护肤品成分表照片
* 肤质类型、护肤习惯、护肤目标等信息
* 反馈、咨询与联系客服时提供的信息

### **1.2 自动收集的信息（用于改善使用体验）**

* 设备型号、操作系统版本
* 日志信息（如崩溃日志）
* 应用使用统计，如使用频率、使用功能类型

我们不收集与身份强绑定的信息（如身份证号、精确地理位置、联系人、支付信息等）。

---

# **2. 信息的使用方式**

我们收集的信息将用于：

1. 提供肤质分析与成分解析等核心功能
2. 生成个性化护肤建议
3. 提升算法精度与应用性能
4. 客服处理、反馈跟踪与产品优化
5. 满足法律法规、监管要求

您的照片仅用于实时分析，不会用于面部识别、身份识别或其他未授权用途。

---

# **3. 信息的存储与保护**

1. 我们在符合国家标准的安全环境中存储数据，并采取加密处理。
2. 照片数据默认在分析完成后自动删除（除非用户明确授权保存历史记录）。
3. 我们不会向任何第三方出售您的数据。
4. 除非为实现必要功能，否则不会共享您的信息。

---

# **4. 第三方服务说明**

如本应用使用第三方 SDK（例：统计分析、云存储），我们将确保其符合隐私保护要求，并在版本更新日志中向用户公开列出。

---

# **5. 您的权利**

根据适用法律，您拥有以下权利：

1. 访问权：您可查看我们存储的您的信息
2. 更正权：您可要求修改不准确的信息
3. 删除权：您可随时要求删除您的数据
4. 撤回授权：您可随时关闭权限或删除账户
5. 获得副本：如需要，我们可向您提供数据副本

---

# **6. 未成年人保护**

未满16周岁的用户应在监护人指导下使用本应用。
如发现误收未成年人数据，我们将立即采取删除措施。

我们可能根据功能迭代或法律要求更新本政策。
更新后将通过应用或公告方式通知用户。
